Class Registration API
Brief:

A simple backend project built with FastAPI and PostgreSQL to collect and store student registration details. Docker was used to containerize the application and database.

Technologies

- Python
- FastAPI
- PostgreSQL
- Docker & Docker Compose
- Pydantic
- Psycopg2

Features

- Accepts student registration details.
- Validates incoming data.
- Stores registration records in PostgreSQL.
- Provides API documentation through Swagger UI.

Run the Project

docker compose up --build -d

Open the API documentation:

"http://localhost:8000/docs"

What I Learned

- Building REST APIs with FastAPI.
- Connecting Python applications to PostgreSQL.
- Working with Docker and Docker Compose.
- Validating data using Pydantic.
